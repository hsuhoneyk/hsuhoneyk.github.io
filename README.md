# Hsu Honey Kyaw — Portfolio

A personal portfolio website for showcasing my web development and UI/UX work.

## Pages

- **Home** — introduction, skills, selected work, and a contact call to action.
- **About** — background and education.
- **Skills** — technologies and areas of interest.
- **Projects** — summaries of FlexiWork, FoodFusion, Goffee Coffee, FitForge, and Fitness Maniac.
- **Contact** — email, phone, and social links.

## Built with

- HTML5
- CSS3
- Font Awesome icons
- Google Fonts (DM Sans and Playfair Display)

## Run locally

Open `index.html` in a browser. The site is static and does not need a build step or server.

This repository contains the portfolio website. The project cards describe the projects, but their individual source code is not currently in this folder. Add each project’s source code or repository link before presenting those projects as code samples for employers to review.
